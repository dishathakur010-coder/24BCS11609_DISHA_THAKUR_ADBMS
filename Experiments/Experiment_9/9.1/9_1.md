# Salary Hike Validation Trigger

This project demonstrates a PostgreSQL **Row-Level BEFORE UPDATE Trigger** on the `Salary_Hike` table.

The trigger restricts a salary increase to a maximum of **15% of the employee's old salary**.

## Features

- Creates a `Salary_Hike` table.
- Creates a trigger function using PL/pgSQL.
- Uses a `BEFORE UPDATE` trigger.
- Uses a `FOR EACH ROW` trigger.
- Compares `NEW.SALARY` with `OLD.SALARY`.
- Allows salary increases up to 15%.
- Raises a custom exception when the increase exceeds 15%.

## Technologies Used

- PostgreSQL
- PL/pgSQL
- SQL
