# Unsold Items – SQL View

## 📌 Project Description

This project demonstrates how to create a **complex SQL view** named `Unsold_Items` using the `Products` and `Order_Details` tables.

The view displays the **ProductName** and **Category** of all products that have **never been ordered by any customer**.

The solution specifically uses the **`NOT IN` operator** to identify products that do not appear in the `Order_Details` table.

---

## 🗂️ Database Tables

### Products

The `Products` table stores information about available products.

| Column      | Data Type    | Description              |
| ----------- | ------------ | ------------------------ |
| ProductID   | INT          | Unique ID of the product |
| ProductName | VARCHAR(100) | Name of the product      |
| Category    | VARCHAR(50)  | Category of the product  |

### Order_Details

The `Order_Details` table stores information about products included in customer orders.

| Column    | Data Type | Description               |
| --------- | --------- | ------------------------- |
| OrderID   | INT       | Unique ID of the order    |
| ProductID | INT       | ID of the ordered product |
| Quantity  | INT       | Quantity ordered          |

---

## ⚙️ SQL Implementation

```sql
CREATE TABLE Products (
    ProductID INT PRIMARY KEY,
    ProductName VARCHAR(100),
    Category VARCHAR(50)
);

CREATE TABLE Order_Details (
    OrderID INT,
    ProductID INT,
    Quantity INT
);

INSERT INTO Products VALUES
(1, 'Laptop', 'Electronics'),
(2, 'Mouse', 'Electronics'),
(3, 'Keyboard', 'Electronics'),
(4, 'Chair', 'Furniture'),
(5, 'Table', 'Furniture');

INSERT INTO Order_Details VALUES
(101, 1, 2),
(102, 2, 1),
(103, 4, 3);

CREATE VIEW Unsold_Items AS
SELECT ProductName, Category
FROM Products
WHERE ProductID NOT IN (
    SELECT ProductID
    FROM Order_Details
);

SELECT * FROM Unsold_Items;
```

---

## 🔍 How It Works

The following subquery finds all products that have been ordered:

```sql
SELECT ProductID
FROM Order_Details;
```

The `NOT IN` operator then selects products whose `ProductID` does **not** appear in that list:

```sql
WHERE ProductID NOT IN (
    SELECT ProductID
    FROM Order_Details
);
```

Finally, the view returns only:

* `ProductName`
* `Category`

for products that have never been ordered.

## 📊 Expected Output

```text
ProductName    Category
-------------------------
Keyboard       Electronics
Table          Furniture
```

In this example:

* **Laptop** → Ordered
* **Mouse** → Ordered
* **Keyboard** → Not ordered
* **Chair** → Ordered
* **Table** → Not ordered

Therefore, **Keyboard** and **Table** are displayed by the `Unsold_Items` view.
