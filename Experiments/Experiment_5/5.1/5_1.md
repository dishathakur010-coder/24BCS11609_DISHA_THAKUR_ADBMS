# SQL Aggregate Functions – Revenue Percentage

## 📌 Problem Statement

Find the percentage of the **total revenue** (sum of all order prices) that is contributed by **American cuisine**.

Requirements:

- Calculate the percentage of revenue from American cuisine.
- Round the result to **2 decimal places**.
- Display the result with the alias **American_Revenue**.

---

# 🗂️ Table Used

## Orders

| Column |
|---------|
| order_id |
| item_name |
| cuisine |
| category |
| price |
| status |

---

# SQL Query

```sql
SELECT
    ROUND(
        (100 * SUM(CASE
            WHEN cuisine = 'American' THEN price
            ELSE 0
        END)) / SUM(price),
        2
    ) AS American_Revenue
FROM Orders;
```

---

# Explanation

- `CASE WHEN cuisine = 'American'` selects only American cuisine orders.
- `SUM(...)` calculates the total revenue from American cuisine.
- `SUM(price)` calculates the overall revenue.
- `(American Revenue / Total Revenue) * 100` computes the percentage.
- `ROUND(..., 2)` rounds the result to 2 decimal places.
- `AS American_Revenue` gives the output column its required name.

---

# SQL Concepts Used

- Aggregate Function (`SUM`)
- Conditional Aggregation (`CASE WHEN`)
- Arithmetic Operations
- ROUND()
- Column Alias (`AS`)

---

# Formula Used

```text
American Revenue % =
(Total American Revenue / Total Revenue) × 100
```

---

# Time Complexity

- **O(n)**

The query scans the `Orders` table only once.
