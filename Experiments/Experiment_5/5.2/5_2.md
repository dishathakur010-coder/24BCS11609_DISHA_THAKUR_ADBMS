# LeetCode 1683 - Invalid Tweets

## Problem

Given a table `Tweets` containing `tweet_id` and `content`, find the IDs of tweets whose content has **more than 15 characters**.

A tweet is considered **invalid** if the length of its content is strictly greater than `15`.

---

## Table Structure

### Tweets

| Column Name | Type |
|------------|------|
| tweet_id | int |
| content | varchar |

- `tweet_id` is the primary key.
- `content` contains the tweet text.

---

## Approach

We can solve this problem using:

- `LENGTH()` → returns the number of characters in the string.
- `WHERE` → filters tweets based on their length.
- `>` → checks if the length is strictly greater than `15`.

### SQL Query

```sql
SELECT tweet_id
FROM Tweets
WHERE LENGTH(content) > 15;
