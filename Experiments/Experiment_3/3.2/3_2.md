# SQL Aggregate Functions with GROUP BY & HAVING

## 📌 Problem Statement

Create an `employees` table, insert employee records, and perform various SQL queries using aggregate functions such as `COUNT()`, `MAX()`, `MIN()`, `AVG()`, `DISTINCT`, along with `GROUP BY` and `HAVING`.

---

## 🗂️ Table Schema

### Employees

| Column | Data Type |
|---------|-----------|
| emp_id | INT |
| emp_name | VARCHAR(100) |
| emp_salary | DECIMAL(10,2) |
| emp_city | VARCHAR(100) |

---

## 📝 Table Creation

```sql
CREATE TABLE employees (
    emp_id INT PRIMARY KEY,
    emp_name VARCHAR(100) NOT NULL,
    emp_salary DECIMAL(10,2) NOT NULL,
    emp_city VARCHAR(100) NOT NULL
);
```

# Queries

## 1️⃣ Count Employees in Each City

### SQL Query

```sql
SELECT emp_city,
       COUNT(emp_id) AS cnt
FROM employees
GROUP BY emp_city
ORDER BY emp_city;
```

### Output

| City | Employees |
|------|----------:|
| Bangalore | 2 |
| Delhi | 2 |
| Kolkata | 1 |
| Mumbai | 2 |

---

## 2️⃣ Find Cities Having Only One Employee

### SQL Query

```sql
SELECT emp_city,
       COUNT(emp_id) AS cnt
FROM employees
GROUP BY emp_city
HAVING COUNT(emp_id) = 1;
```

### Output

| City | Employees |
|------|----------:|
| Kolkata | 1 |

---

## 3️⃣ Find Cities Having At Least Two Employees

### SQL Query

```sql
SELECT emp_city,
       COUNT(emp_id) AS cnt
FROM employees
GROUP BY emp_city
HAVING COUNT(emp_id) > 1;
```

### Output

| City | Employees |
|------|----------:|
| Bangalore | 2 |
| Delhi | 2 |
| Mumbai | 2 |

---

## 4️⃣ Find the Maximum Salary in Each City

### SQL Query

```sql
SELECT emp_city,
       MAX(emp_salary) AS max_salary
FROM employees
GROUP BY emp_city;
```

### Output

| City | Max Salary |
|------|-----------:|
| Bangalore | 110000 |
| Delhi | 60000 |
| Kolkata | 72000 |
| Mumbai | 95000 |

---

## 5️⃣ Find the Minimum Salary in Each City

### SQL Query

```sql
SELECT emp_city,
       MIN(emp_salary) AS min_salary
FROM employees
GROUP BY emp_city;
```

### Output

| City | Min Salary |
|------|-----------:|
| Bangalore | 105000 |
| Delhi | 55000 |
| Kolkata | 72000 |
| Mumbai | 85000 |

---

## 6️⃣ Find the Average Salary in Each City

### SQL Query

```sql
SELECT emp_city,
       ROUND(AVG(emp_salary), 2) AS avg_salary
FROM employees
GROUP BY emp_city;
```

> **PostgreSQL Alternative**

```sql
SELECT emp_city,
       AVG(emp_salary)::NUMERIC(10,2) AS avg_salary
FROM employees
GROUP BY emp_city;
```

### Output

| City | Average Salary |
|------|---------------:|
| Bangalore | 107500.00 |
| Delhi | 57500.00 |
| Kolkata | 72000.00 |
| Mumbai | 90000.00 |

---

## 7️⃣ Find All Distinct Cities

### SQL Query

```sql
SELECT DISTINCT emp_city
FROM employees;
```

### Output

| City |
|------|
| Mumbai |
| Delhi |
| Bangalore |
| Kolkata |

---

# 🔑 Difference Between WHERE and HAVING

| WHERE | HAVING |
|--------|---------|
| Filters rows before grouping | Filters groups after grouping |
| Cannot use aggregate functions | Can use aggregate functions |
| Executed before `GROUP BY` | Executed after `GROUP BY` |

---

# ⏱️ Time Complexity

Most of these queries run in:

**O(n)**

where `n` is the number of rows in the `employees` table.

---

# ✅ Summary

This practice demonstrates how to:

- Count records using `COUNT()`
- Find maximum, minimum, and average values
- Group data using `GROUP BY`
- Filter grouped data using `HAVING`
- Retrieve unique values using `DISTINCT`
- Sort results using `ORDER BY`

These are some of the most commonly used SQL aggregation techniques in interviews and real-world database applications.
