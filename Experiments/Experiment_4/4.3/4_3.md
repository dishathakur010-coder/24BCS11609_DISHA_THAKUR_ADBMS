# Joins Practice-3

A collection of SQL JOIN practice problems focused on mastering different types of joins and understanding relationships between tables in a relational database.

## 📖 Overview

This project contains practical SQL exercises using a sample database consisting of customers, orders, products, categories, and employees. The problems help reinforce JOIN concepts commonly asked in interviews and database courses.

## 📂 Database Tables

The exercises use the following tables:

- Customers
- Orders
- Products
- Categories
- Employees

## 📝 Problems

### 1. Employee and Manager Names
Retrieve a list of employees along with their respective managers using a **SELF JOIN**.

### 2. Every Possible Combination
Generate every possible combination of customer names and product names using a **CROSS JOIN**.

## 🛠️ SQL Concepts Used

- SELF JOIN
- LEFT JOIN
- CROSS JOIN
- Table Aliases
- Employee-Manager Relationships
- Cartesian Product

## 📚 Learning Outcomes

By completing these exercises, you will learn how to:

- Perform SELF JOINs on the same table.
- Retrieve hierarchical employee-manager relationships.
- Generate Cartesian products using CROSS JOIN.
- Use table aliases to improve query readability.
- Understand relationships between multiple tables.
