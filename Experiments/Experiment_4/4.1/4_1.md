# SQL JOINs Practice - Customers, Orders, Products & Categories

## 📌 Problem Statement

Practice different types of SQL `JOIN` operations using the given tables:

- **customers**
- **orders**
- **products**
- **categories**

Solve the following queries:

1. Display all orders along with the corresponding customer details.
2. Display all products with their category names.
3. Display every category along with its product name and price.

# 1️⃣ All Orders with Customer Details

### SQL Query

```sql
SELECT
    c.customer_name,
    o.order_id,
    o.customer_id,
    o.product_name,
    o.order_date,
    o.quantity
FROM customers AS c
INNER JOIN orders AS o
ON c.customer_id = o.customer_id;
```

### Explanation

- Joins the `customers` and `orders` tables.
- Returns only matching records.
- Displays customer information together with order details.

---

# 2️⃣ Products with Category Names

### SQL Query

```sql
SELECT
    p.product_name,
    c.category_name
FROM products AS p
INNER JOIN categories AS c
ON p.category_id = c.category_id;
```

### Explanation

- Joins the `products` table with the `categories` table.
- Retrieves the category corresponding to each product.

---

# 3️⃣ Category Names with Product Details

### SQL Query

```sql
SELECT
    c.category_name,
    p.product_name,
    p.price
FROM products AS p
INNER JOIN categories AS c
ON p.category_id = c.category_id;
```

### Explanation

- Joins products with categories.
- Displays the category name, product name, and product price.

# 🔑 INNER JOIN

`INNER JOIN` returns **only the rows that have matching values in both tables**.

### Syntax

```sql
SELECT columns
FROM table1
INNER JOIN table2
ON table1.column = table2.column;
```

---

# ⏱️ Time Complexity

For each query:

- **O(n × m)** (without indexes)
- **Approximately O(n log n)** with indexed join columns in most database systems.
