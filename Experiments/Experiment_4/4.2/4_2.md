# SQL FULL OUTER JOIN - Student and Course Tables

## 📌 Problem Statement

Write a SQL query to perform a **FULL OUTER JOIN** between the `student` and `course` tables using the `Course_id` column.

The query should return:

- Student ID
- Student Name
- Department
- Student Course ID
- Course ID
- Course Name
- Credits
- Professor ID

The result should include **all records from both tables**, with `NULL` values where no matching record exists.

---

## 🗂️ Tables Used

### Student

| Column |
|--------|
| St_id |
| St_Name |
| Department |
| Course_id |

---

### Course

| Column |
|--------|
| Course_id |
| Course_Name |
| Credits |
| Prof_id |

---

## 📝 SQL Query

```sql
SELECT
    s.St_id,
    s.St_Name,
    s.Department,
    s.Course_id,
    c.Course_id,
    c.Course_Name,
    c.Credits,
    c.Prof_id
FROM student AS s
FULL OUTER JOIN course AS c
ON s.Course_id = c.Course_id;
```

---

## 📖 Explanation

- `FULL OUTER JOIN` combines all rows from both the `student` and `course` tables.
- Matching rows are joined together based on `Course_id`.
- If a student has no matching course, the course columns contain `NULL`.
- If a course has no matching student, the student columns contain `NULL`.

## 🔄 Types of JOIN

| JOIN | Description |
|------|-------------|
| **INNER JOIN** | Returns only matching rows from both tables. |
| **LEFT JOIN** | Returns all rows from the left table and matching rows from the right table. |
| **RIGHT JOIN** | Returns all rows from the right table and matching rows from the left table. |
| **FULL OUTER JOIN** | Returns all rows from both tables, filling unmatched values with `NULL`. |

---

## 💡 Key Points

- Returns every row from both tables.
- Matching records are merged into one row.
- Unmatched rows contain `NULL` values.
- Useful when no data should be lost from either table.

---

## ⏱️ Time Complexity

- **O(n × m)** without indexes.
- Modern database systems optimize joins using indexes, reducing the execution time significantly.
