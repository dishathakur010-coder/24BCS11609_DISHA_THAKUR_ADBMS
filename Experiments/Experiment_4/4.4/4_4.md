# SQL SELF JOIN

## 📌 Problem Statement

This exercise demonstrates how to use a **SELF JOIN**, where a table is joined with itself using different aliases.

The tasks are:

1. Find pairs of students who belong to the **same department**.
2. Find students who have selected the **same favorite Course_id**, displaying only one record for each student and ordering the results by `Course_id`.

---

# 🗂️ Table Used

## Student

| Column |
|---------|
| St_id |
| St_Name |
| Department |
| Course_id |

---

# 1️⃣ Students in the Same Department

### SQL Query

```sql
SELECT
    s1.St_id,
    s1.St_Name,
    s1.Department,
    s2.St_id,
    s2.St_Name,
    s2.Department
FROM student AS s1
INNER JOIN student AS s2
ON s1.Department = s2.Department
AND s1.St_id != s2.St_id;
```

### Explanation

- The `student` table is joined with itself.
- `s1` and `s2` are aliases representing two instances of the same table.
- Students are matched when they belong to the same department.
- `s1.St_id != s2.St_id` ensures a student is not paired with themselves.

---

# 2️⃣ Students with the Same Favorite Course

### SQL Query

```sql
SELECT DISTINCT
    s1.St_id,
    s1.St_Name,
    s1.Course_id
FROM student AS s1
INNER JOIN student AS s2
ON s1.Course_id = s2.Course_id
AND s1.St_id != s2.St_id
ORDER BY s1.Course_id;
```

### Explanation

- Matches students having the same `Course_id`.
- `DISTINCT` removes duplicate rows.
- Results are sorted by `Course_id` in ascending order.

# 📚 SQL Concepts Used

- SELF JOIN
- INNER JOIN
- Table Aliases (`s1`, `s2`)
- DISTINCT
- ORDER BY
- Comparison using `!=`

---

# 🔄 SELF JOIN Overview

| Feature | Description |
|---------|-------------|
| Table Aliases | Treat the same table as two different tables. |
| INNER JOIN | Finds matching rows within the same table. |
| DISTINCT | Removes duplicate results. |
| ORDER BY | Sorts the output in ascending order. |

---

# 💡 Key Points

- A **SELF JOIN** joins a table with itself.
- Aliases (`s1`, `s2`) are mandatory to distinguish the two instances.
- `s1.St_id != s2.St_id` avoids matching a row with itself.
- `DISTINCT` helps eliminate duplicate records.
- `ORDER BY` sorts the final output.

---

# ⏱️ Time Complexity

With indexing:

Without indexing:

- **O(n²)**
