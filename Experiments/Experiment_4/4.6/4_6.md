# SQL INNER JOIN & LEFT JOIN

## 📌 Problem Statement

Learn the difference between **INNER JOIN** and **LEFT JOIN** by joining the `student` and `course` tables using the `Course_id` column.

Perform the following queries:

1. Join both tables using **INNER JOIN**.
2. Join both tables using **LEFT JOIN**.

---

---

# 1️⃣ INNER JOIN

### SQL Query

```sql
SELECT *
FROM student
JOIN course
ON student.Course_id = course.Course_id;
```

### Explanation

- `INNER JOIN` returns only the rows where `Course_id` exists in both tables.
- Students whose course does not exist in the `course` table are excluded.

---

# 2️⃣ LEFT JOIN

### SQL Query

```sql
SELECT *
FROM student
LEFT JOIN course
ON student.Course_id = course.Course_id;
```

### Explanation

- `LEFT JOIN` returns **all rows from the `student` table**.
- Matching course details are displayed.
- If no matching course exists, the course columns contain **NULL** values.

# 🔄 JOIN Comparison

| JOIN Type | Result |
|-----------|--------|
| **INNER JOIN** | Returns only matching rows from both tables. |
| **LEFT JOIN** | Returns all rows from the left table and matching rows from the right table. |

---

# 💡 Key Points

### INNER JOIN

- Displays only records that exist in both tables.
- Ignores unmatched rows.

### LEFT JOIN

- Returns every row from the left table.
- Unmatched rows in the right table appear as `NULL`.

---

# ⏱️ Time Complexity

With proper indexing on `Course_id`:

- **INNER JOIN:** O(n log n)
- **LEFT JOIN:** O(n log n)

Without indexes, performance may approach **O(n × m)** depending on the database engine.
