# PostgreSQL Employee Insert Procedure

This project demonstrates a PostgreSQL stored procedure that inserts employee details into an `Employee` table only when the `EMP_ID` is an odd number.

## Features

- Creates an `Employee` table.
- Creates a stored procedure named `Insert_Employee`.
- Checks whether `EMP_ID` is odd or even.
- Allows insertion only for odd `EMP_ID`.
- Raises an exception for even `EMP_ID`.
- Displays a success message after successful insertion.

## Technologies Used

- PostgreSQL
- PL/pgSQL
- SQL

## Procedure

The `Insert_Employee` procedure accepts the following parameters:

- `EMP_ID`
- `EMP_NAME`
- `SALARY`
- `DEPARTMENT_NAME`
