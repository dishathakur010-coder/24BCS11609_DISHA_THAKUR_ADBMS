# Primary Key vs Foreign Key

## Problem Statement

Understand the difference between **Primary Key** and **Foreign Key** in a database.

A **Primary Key** uniquely identifies each record in a table, while a **Foreign Key** is a field that refers to the primary key of another table.

## Key Concepts

### Primary Key

- Uniquely identifies each row in a table.
- Cannot contain `NULL` values.
- Cannot contain duplicate values.
- A table can have only one primary key constraint.

### Foreign Key

- Refers to the primary key of another table.
- Creates a relationship between two tables.
- Can contain duplicate values.
- Can contain `NULL` values unless specified as `NOT NULL`.

## Example

### Student Table

| St_id | St_Name | Department | Course_id |
|---|---|---|---|
| 1001 | John Smith | Computer Science | CS101 |
| 1002 | Emily Brown | History | HIS102 |
| 1003 | David Lee | Mathematics | MAT202 |

Here, `St_id` is the **Primary Key**.

`Course_id` is a **Foreign Key** because it refers to `Course_id` in the `course` table.

### Course Table

| Course_id | Course_Name | Credits |
|---|---|---:|
| CS101 | Introduction to Computer Science | 3 |
| HIS102 | World History II | 3 |
| MAT202 | Linear Algebra | 2 |

Here, `Course_id` is the **Primary Key**.

## Correct Answer

**Foreign key is a field in one table that refers to the primary key of another table.**
