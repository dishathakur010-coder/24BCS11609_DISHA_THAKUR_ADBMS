# Snapchat Time Spent Breakdown

## Problem Statement

Given information about Snapchat users, including their age groups and time spent sending and opening snaps, calculate the percentage of total time spent on each activity.

The output should show the breakdown of time spent **sending vs. opening snaps**, grouped by age group.

The percentages should be rounded to **2 decimal places**.

## Tables Used

### activities

- `activity_id`
- `user_id`
- `activity_type`
- `time_spent`
- `activity_date`

### age_breakdown

- `user_id`
- `age_bucket`

## SQL Query

```sql
SELECT
    ab.age_bucket,
    ROUND(
        100.0 * SUM(CASE WHEN a.activity_type = 'send' THEN a.time_spent ELSE 0 END)
        / SUM(CASE WHEN a.activity_type IN ('send', 'open') THEN a.time_spent ELSE 0 END),
        2
    ) AS send_perc,
    ROUND(
        100.0 * SUM(CASE WHEN a.activity_type = 'open' THEN a.time_spent ELSE 0 END)
        / SUM(CASE WHEN a.activity_type IN ('send', 'open') THEN a.time_spent ELSE 0 END),
        2
    ) AS open_perc
FROM activities a
JOIN age_breakdown ab
    ON a.user_id = ab.user_id
WHERE a.activity_type IN ('send', 'open')
GROUP BY ab.age_bucket;
