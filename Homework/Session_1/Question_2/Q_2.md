# Repeated Payments

## Problem Statement

Given a `transactions` table, find the number of repeated payments.

A payment is considered repeated if:
- It is made to the same merchant.
- It uses the same credit card.
- It has the same amount.
- It occurs within 10 minutes of a previous transaction.

The first transaction should not be counted.

## Solution

```sql
SELECT COUNT(*) AS payment_count
FROM transactions t1
WHERE EXISTS (
    SELECT 1
    FROM transactions t2
    WHERE t2.merchant_id = t1.merchant_id
      AND t2.credit_card_id = t1.credit_card_id
      AND t2.amount = t1.amount
      AND t2.transaction_timestamp < t1.transaction_timestamp
      AND t1.transaction_timestamp <= t2.transaction_timestamp + INTERVAL '10 minutes'
);
