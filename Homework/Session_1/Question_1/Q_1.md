# Tweets' Rolling Averages

## Problem Statement

Given a table of tweet data over a specified time period, calculate the **3-day rolling average of tweets for each user**.

The output should contain the user ID, tweet date, and rolling average rounded to 2 decimal places.

## Table Used

**tweets**

- `user_id` - Integer
- `tweet_date` - Timestamp
- `tweet_count` - Integer

## SQL Query

```sql
SELECT
    user_id,
    tweet_date,
    ROUND(
        AVG(tweet_count) OVER (
            PARTITION BY user_id
            ORDER BY tweet_date
            ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
        ),
        2
    ) AS rolling_avg_3d
FROM tweets
ORDER BY user_id, tweet_date;
